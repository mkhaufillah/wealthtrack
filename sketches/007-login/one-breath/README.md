## Variant: Satu napas

### Design stance
Gak ada wordmark. Ayam + satu kalimat, field tanpa label Inggris.

### Key choices
- Layout: udara banyak, form tipis
- Typography: tagline 15px, field placeholder
- Color: field nyatu ke bg, tombol rose
- Interaction: show/hide sandi, toast Masuk

### Trade-offs
- Strong at: ramah, beda dari template
- Weak at: brand name gak kebaca buat orang baru

### Best for
Cuma Filla/Nahda yang masuk — bukan onboarding publik.
