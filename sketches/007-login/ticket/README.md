## Variant: Tiket bawah

### Design stance
Jempol dulu — ayam di langit-langit, form nempel bawah.

### Key choices
- Layout: mascot + sapa di atas, tiket putih di bottom
- Typography: Nunito
- Color: peach bg, rose Masuk
- Interaction: fokus field → ayam mengecil; light/dark

### Trade-offs
- Strong at: satu tangan, keyboard
- Weak at: layar pendek + keyboard masih rapat

### Best for
Pakai tiap hari, buka sambil rebahan.
