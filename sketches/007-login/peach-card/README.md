## Variant: Kartu peach

### Design stance
Login = saudara kandung kartu Uang kamu.

### Key choices
- Layout: slab peach + ayam di dalam, field di kartu putih
- Typography: Nunito 800 judul
- Color: heroFill / surface
- Interaction: error inline, light/dark

### Trade-offs
- Strong at: konsisten sama home
- Weak at: agak “aman”, masih vertikal tengah

### Best for
Kalau rombak login harus terasa satu keluarga sama Beranda.
