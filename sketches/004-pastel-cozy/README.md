## Variant: Pastel cozy

### Design stance
Household money app that feels like a note from Nahda — warm, icon-led, never stern.

### Key choices
- Layout: greeting + peach hero with wallet glyph; icon wells for pots/debt/AI
- Typography: Nunito (rounded, friendly)
- Color: peach cream, mint, lilac, butter — no forest slab
- Interaction: light/dark, tab Transaksi, FAB kamera

### Trade-offs
- Strong at: approachable, scannable icons, family app
- Weak at: “serious wealth” gravitas

### Best for
Default if Filla wants friendly over editorial.
