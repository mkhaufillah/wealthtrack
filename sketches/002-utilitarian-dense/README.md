## Variant: Utilitarian dense

### Design stance
A household ledger you scan in two seconds — numbers aligned, almost no cards.

### Key choices
- Layout: compact header band, two-up pots, tight txn rows
- Typography: IBM Plex Sans + Plex Mono amounts
- Color: same Saffron Ink, less surface chrome
- Interaction: date chips filter the list; light/dark

### Trade-offs
- Strong at: power-user scan, more info above the fold
- Weak at: warmth / “eye-catchy” first impression

### Best for
Filla daily driver if he hates scrolling the current home.
