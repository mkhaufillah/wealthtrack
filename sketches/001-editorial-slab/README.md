## Variant: Editorial slab

### Design stance
One dark slab carries the only large number; the rest of the page is quiet paper.

### Key choices
- Layout: phone column, hero slab first, secondary modules stacked
- Typography: Fraunces for money, Outfit for UI
- Color: Saffron Ink — gold hairline on forest slab
- Interaction: light/dark, tab to Transaksi, FAB toast

### Trade-offs
- Strong at: glanceable saldo, trust, matching docs/20
- Weak at: seeing debt + pots in one glance (must scroll)
