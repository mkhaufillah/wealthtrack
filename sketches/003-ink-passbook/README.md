## Variant: Ink passbook

### Design stance
The phone chrome *is* the hero — full-bleed ink header, paper body like a bank book.

### Key choices
- Layout: status+hero fused, no floating card; cash/utang switch
- Typography: Newsreader figures, Manrope UI
- Color: ink occupies the top third; saffron only on the rule and FAB
- Interaction: Uang tunai / Utang swap the hero figure; light/dark

### Trade-offs
- Strong at: distinctive, photo-worthy, cash vs debt without mixing math
- Weak at: 5-tab Material familiarity; more APK layout work

### Best for
If the slab still feels “just another card”.
