## Variant: Overlay

### Design stance
List stays clean. Tap the fake field, sheet takes over with keyboard, recent queries, live hits.

### Key choices
- Layout: compact trigger on page, full search in bottom sheet
- Interaction: open/close sheet, type to filter

### Trade-offs
- Strong at: recents, focus, less clutter on the list
- Weak at: one extra tap

### Best for
If search is occasional, not every visit.
