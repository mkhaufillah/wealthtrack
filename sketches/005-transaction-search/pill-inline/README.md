## Variant: Pill inline

### Design stance
Search stays on the list. Small 16px icon, 44px bar, chips under it. Closest to today, less noisy.

### Key choices
- Layout: bar then horizontal chips then list
- Interaction: type filters rows, chips filter type

### Trade-offs
- Strong at: one-hand, no extra screen
- Weak at: chips steal vertical space

### Best for
Default if Filla just wants the icon smaller and search less fat.
