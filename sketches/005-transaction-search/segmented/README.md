## Variant: Segmented

### Design stance
Search is the header. Type + Semua/Keluar/Masuk as a 3-segment control. No extra category chip row.

### Key choices
- Layout: 48px pill search, segmented control, dated list
- Interaction: segment + type together

### Trade-offs
- Strong at: type filter always visible, fewer controls
- Weak at: category filter needs another entry (not on this sketch)

### Best for
If All/Expense/Income is the main split, categories less often.
