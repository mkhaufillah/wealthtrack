## Variant: Amount first

### Design stance
Uang dulu. Jumlah jadi hero, field lain ikut di bawah.

### Key choices
- Layout: angka besar di tengah, segmented Keluar/Masuk, form scroll, Simpan nempel bawah
- Typography: Nunito 800 untuk nominal
- Color: peach cozy, tombol aksen pink
- Interaction: ganti tipe reset kategori; Simpan toast

### Trade-offs
- Strong at: isi cepat jumlah
- Weak at: scan struk tersembunyi di header

### Best for
Pencatatan harian tanpa struk
