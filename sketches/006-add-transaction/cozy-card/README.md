## Variant: Cozy card

### Design stance
Satu kartu. Tipe + jumlah + kategori grid, field lain rapat.

### Key choices
- Layout: kartu putih full, nominal di peach, kategori 2 kolom
- Typography: Nunito
- Color: chip terpilih pakai aksen
- Interaction: ganti Keluar/Masuk ganti grid kategori

### Trade-offs
- Strong at: semua field kelihatan tanpa hero berlebih
- Weak at: scan hanya ikon kecil

### Best for
Rasa pastel cozy yang konsisten dengan search C
