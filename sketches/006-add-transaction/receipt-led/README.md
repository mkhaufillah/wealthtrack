## Variant: Receipt led

### Design stance
Struk dulu. OCR jadi jalan utama, form manual tetap lengkap di bawah.

### Key choices
- Layout: kartu peach Foto/Galeri, pemisah “atau isi sendiri”, form sama
- Typography: Nunito
- Color: aksen di aksi foto
- Interaction: sheet kamera/galeri

### Trade-offs
- Strong at: alur scan tidak tersembunyi
- Weak at: form manual lebih jauh scroll

### Best for
Orang yang sering foto struk
