## Variant: Pastel garden

### Design stance
Home is a garden of tinted tiles — tap the picture, not the paragraph.

### Key choices
- Layout: 2×2 icon tiles (tabungan, darurat, utang, AI) under a mint greeting chip
- Typography: Nunito
- Color: each tile owns a pastel (mint / butter / blush / lilac)
- Interaction: tile press state, cash/utang chip, Transaksi tab

### Trade-offs
- Strong at: friendliest, most “icon-y”, kids-of-the-house glanceable
- Weak at: one-hero-number discipline; more chrome

### Best for
If cozy still feels too much like a bank card.
