# 32 — Multi-language (id-ID / en-US)

**Status:** Specified; implementation follows this doc.

**See also:** [03 Backend API](03-backend-api.md) · UI bootstrap / `ui_copy`

Docs and README stay English. On-screen strings come from `ui_copy` via `t(key)`.

## Goal

The user can switch **Bahasa Indonesia** and **English**. Copy and category labels both use **keys**, same catalog.

1. Every `ui_copy` key has `id-ID` and `en-US` rows.
2. Every category has `copy_key` (e.g. `cat.n.food`). The label is `t(copy_key)`, not a second name column.
3. Profile → Tampilan: language switch. Persisted on the user (`users.locale`) and on device.
4. **First launch onboarding** — pick language before login. Cute chicken illustrations in `mobile/assets/onboarding/`. Flag `onboarding_done` in secure storage. Skip if already done. Language can still change later in Profile.

## Onboarding

Route `/onboarding`. Shown when `onboarding_done` is missing.

1. Language: Indonesia / English (labels always bilingual). Copy switches **instantly** from bundled fallback (`copy_fallback` / `copy_fallback_en`); live `GET /ui/bootstrap?locale=` overlays when it returns. Bootstrap cache is **per locale**. Overlapping taps drop stale responses.
2. Slide: log money without drama.
3. Slide: bank notification → a draft.

**Mulai** writes `onboarding_done=1` and `ui_locale`, then `/login`.

Assets (bundled, not CDN):

- `assets/onboarding/lang.jpg`
- `assets/onboarding/money.jpg`
- `assets/onboarding/bank.jpg`

Copy keys: `onboarding.*`, `err.*` (API errors via `X-Locale` + `code`), `mail.otp.subject` / `mail.otp.body` (SMTP OTP, `{otp}` placeholder, locale from `X-Locale`).

Bundled Dart fallback maps must stay **single-line** string literals (`\\n` escapes). Real newlines inside `'…'` break `flutter test`.

## Non-goals

- More than two locales.
- Translating transaction descriptions, notes, or OCR text.
- Per-household language (locale is per user).
- Changing Debt Tracker behaviour.
- Hardcoded hex / new theme tokens.

## Locales

| Code | UI |
|---|---|
| `id-ID` | Indonesia (default) |
| `en-US` | English |

Aliases: `id` → `id-ID`, `en` → `en-US`. Anything else → `id-ID`.

## Copy

Table `ui_copy (key, locale, value)` already exists. Seed both locales (`COPY_ID`, `COPY_EN`). `ON CONFLICT DO NOTHING` — never overwrite live edits.

`GET /ui/bootstrap?locale=en-US`

- Load `id-ID` first, overlay the requested locale (missing EN keys stay Indonesian).
- Response `locale` is the requested locale, not `ui_config.locale`.
- Redis key `ui:bootstrap:{locale}`.

Offline Flutter fallback (`copyFallback` / `copyFallbackEn`) is bundled. After bootstrap, `remoteCopy` overlays the chosen locale.

Switching language **must remount** the navigator (`KeyedSubtree` on `uiLocale`). `t()` is not Flutter l10n, so GoRouter would otherwise keep stale widgets.

Admin Copy catalog toggle (`_catalogLocale`) edits `ui_copy` per language. It is **not** the app language switch (that lives in Profile). Dark-mode SegmentedButton uses `AppTheme.segmentedButtonStyle` (accent selected, card unselected).

New keys (ID seed = fallback):

- `profile.language` — Bahasa / Language
- `profile.lang_id` — Indonesia
- `profile.lang_en` — English
- `profile.copy_locale_hint` — catalog vs app language
- `date.today` / `date.yesterday` / `date.days_ago`

## User locale

`users.locale TEXT NOT NULL DEFAULT 'id-ID'`.

`GET /auth/me` includes `locale`.

`PUT /auth/me` accepts `locale` (`id-ID` \| `en-US`).

Flutter: persist `ui_locale` on device. Login copies `user.locale` if present. Switch: save local → PUT `/auth/me` → reload bootstrap → `MaterialApp.locale`.

Unauthenticated screens (login) use the device-stored locale. `POST /auth/send-otp` reads `X-Locale` and renders `mail.otp.*` from the catalog (not hardcoded English/Indonesian).

Household **display** of built-in names `Home` / `Household` / `Keluarga` / `Rumah` uses `t('hh.default_name')`. Custom names stay as stored in `households.name`.

## Guardrails

- `COPY_ID` keys == `copyFallback` keys and values (existing `test_ui_seed_sync`).
- `COPY_EN` keys == `COPY_ID` keys (new).
- Widget tests stay on `id-ID`.
